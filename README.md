# VK Music Saver (Firefox Extension)

> **100% written by Antigravity (Gemini 3.8 Flash)** — весь исходный код, архитектура, бинарные парсеры/муксеры, интерфейс настроек, тесты и сборочные скрипты этого проекта полностью написаны ИИ-агентом **Antigravity** (модель **Gemini 3.8 Flash**) по постановке задачи от [@slimefrozik](https://github.com/slimefrozik).

Расширение для Firefox (Manifest V2, Firefox `140.0+`), которое добавляет кнопку скачивания треков в интерфейсе `vk.com` и `vk.ru` рядом со штатными кнопками плеера и списков треков, а также предоставляет панель настроек.

## Возможности

- **Кнопка скачивания рядом со штатными элементами VK**: «Транслировать аудиозаписи:» и «Открыть сниппет» по умолчанию остаются на месте, а кнопка скачивания добавляется рядом (в плеере и в строках треков).
- **Гибкие настройки (по клику на иконку расширения или в `about:addons` → Настройки)**:
  - **Качество потока (HLS):** максимальное (лучший битрейт), среднее или экономное.
  - **Предпочитаемый формат:** Авто (MP3 / M4A без потерь), MP3, M4A (контейнер для AAC) или сырой AAC (ADTS).
  - **Имя файла:** `Исполнитель - Название`, `Название - Исполнитель` или `Только Название`.
  - **Встраивание метаданных:** запись ID3v2.3 (`TIT2`/`TPE1`, UTF-16LE) для MP3 и iTunes-атомов (`©nam`/`©ART`) для M4A.
  - **Настройка интерфейса VK (применяется мгновенно без перезагрузки вкладки):** показ/скрытие кнопки скачивания в плеере и строках треков, скрытие кнопок «Транслировать аудиозаписи:» и «Открыть сниппет», отключение всплывающих уведомлений об ошибках.
- **Локальная обработка без перекодирования:** встроенные расшифровщик `AES-128-CBC`, MPEG-TS демультиплексор и ADTS→M4A упаковщик.

## Сборка пакета

```bash
node scripts/build.mjs
```

Соберёт пакеты `dist/vk-music-saver-1.1.0.xpi` и `dist/vk-music-saver-1.1.0.zip`.

## Установка в Firefox

1. Скачайте `.xpi` из раздела **Releases** (или соберите локально командой `node scripts/build.mjs`).
2. Откройте `about:debugging#/runtime/this-firefox` в Firefox (версия 140+).
3. Нажмите **«Загрузить временное дополнение…»** (*Load Temporary Add-on…*).
4. Выберите `manifest.json` или собранный файл `dist/vk-music-saver-1.1.0.xpi`.

> В обычной релизной версии Firefox неподписанные дополнения работают до перезапуска браузера. Для постоянной установки подпишите `dist/vk-music-saver-1.1.0.zip` через кабинет разработчика Mozilla (AMO) как *Self-distributed (Unlisted)* и установите полученный подписанный `.xpi`.
